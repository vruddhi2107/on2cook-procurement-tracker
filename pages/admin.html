Pipeline Editor
View and understand each pipeline's phase sequence. Green phases are active; red-bordered phases are terminal (auto-close the request). Toggle optional phases on/off per pipeline.
ℹ How to add a new phase: Phase changes require a code + database update. Use the form below to document the new phase, then apply via a Supabase migration. The system will enforce it in the workflow track automatically once PIPELINE_WF_STEPS is updated in js/supabase-config.js.
Force Phase Override
Move any request to any phase — bypasses the normal workflow. Use only when a request is stuck or data needs correction.
This directly modifies the database. Use sparingly. All overrides are logged as comments on the request.

Filter Builder
Controls the filter bar on request-list pages. Add a filter for any field — including anything actually written on your requests, auto-detected from live data — choose single-select, multi-select, text search, or date range, decide which roles see it, then reorder or hide it.

Column Manager
Controls which columns show in the Master Dashboard requests table, and their order. "Actions" always stays last.
Stat Cards
Controls the KPI cards row at the top of the Master Dashboard. Toggle the built-in ones, or add a custom "count where field = value" card.
Custom Fields
Fields you add here appear on the Engineer's "New Request" form and are saved per-request. They're also selectable as filters, table columns, and export columns.
Departments
Add departments beyond the built-in list. New ones appear immediately in the "Add User" department dropdown, filters, and table columns everywhere in the app.

Phase Display
Rename, recolor, or re-icon any existing phase's label everywhere it appears (badges, filters, exports). This only changes display — it can't add/remove phases or change what triggers a phase transition, since that's wired into the live workflow logic. To add a genuinely new phase, use the Pipeline Editor's "document a new phase" form, which needs a short code change.
Export Config
Choose which columns are included when Master Admin clicks "Export CSV" on the Dashboard.
Nav Visibility
Hide top-nav links for a role. This only hides the link in the UI — it does not change database permissions, so it's not a security control. Use it to declutter, not to restrict access to sensitive data.
Workflow Map
For every phase in every pipeline: which role's action moves it forward, and how many live requests are sitting there right now. This is a read-only map, not an editor — the actual phase-to-phase logic lives in code (see the note below), so this is the safe way to get full visibility without risking a live workflow change. Rename a phase's display label from the Phase Display panel; it'll update here too.
Why isn't this editable? Every "what happens next" rule (who approves what, which phase comes after which) is written directly into each role's page — that's what keeps a live procurement system predictable. Turning this into a true drag-and-drop workflow editor means replacing that code with a data-driven rules engine everywhere at once, which is a real, riskier project of its own. Flag it if you want to scope that properly — it shouldn't be done as a quiet add-on to a customization panel.
